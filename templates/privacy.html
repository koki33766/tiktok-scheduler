Privacy Policy

Last updated: 2026-05-29

1. Overview

TikTok Scheduler ("the App") is a personal tool that allows users to schedule and publish videos to their own TikTok account using the TikTok Content Posting API. This privacy policy describes what data is collected and how it is used.

2. Data We Collect

  • TikTok User ID (open_id): Used to identify the authenticated user.
  • OAuth Access Token: Used to call the TikTok API on behalf of the user. Stored in a server-side session only.
  • Video files: Uploaded by the user and submitted to TikTok via the API. Not stored on our servers.

3. How We Use Data

All collected data is used solely to provide the scheduling and posting functionality. We do not use the data for advertising, analytics, or any other purpose.

4. Data Sharing

We do not sell, share, or disclose any user data to third parties. Data is transmitted only between the user's browser, this application, and TikTok's official API endpoints.

5. Third-Party Accounts

The App accesses only the TikTok account of the currently authenticated user. No third-party accounts or data are accessed.

6. Data Retention

Session data (access token, user ID) is stored temporarily in the server session and is cleared upon logout or session expiration. No data is persisted to a database.

7. TikTok Platform Policy Compliance

This application complies with TikTok's Terms of Service and Developer Platform Policy. TikTok data is not used beyond the scope approved in our API application.
