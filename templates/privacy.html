Privacy Policy

Effective date: May 29, 2026  ·  Last updated: May 29, 2026

1. Overview

PostFlow ("the App", "we", "our") is a personal video scheduling tool built for individual TikTok creators. It allows users to upload video files and schedule them for automatic publication to their own TikTok account using TikTok's official Content Posting API.

This Privacy Policy explains what data we collect, how we use it, and your rights regarding that data. By using PostFlow, you agree to the practices described here.

2. Data We Collect

PostFlow collects only the minimum data necessary to provide its scheduling functionality:

Data Source Purpose Retention
TikTok User ID (open_id) TikTok OAuth Identify the authenticated user's account Session only — cleared on logout
OAuth Access Token TikTok OAuth Authorize API calls on behalf of the user Session only — cleared on logout
Video files User upload Submitted to TikTok Content Posting API Not stored — transmitted directly to TikTok
Caption & hashtags User input Included in the scheduled post metadata Deleted after posting

3. How We Use Your Data

All data collected is used exclusively to operate the scheduling and posting feature. Specifically:

  • Your TikTok credentials are used solely to authenticate API requests to your own account.
  • Video files and captions are used solely to publish the post you have scheduled.
  • We do not use your data for advertising, profiling, or any purpose beyond the core functionality.

4. Data Sharing and Disclosure

We do not sell, rent, or share your personal data with any third parties, except:

  • TikTok API: Video content and metadata are transmitted to TikTok's official API endpoints solely to fulfill your scheduled posts. This transmission is governed by TikTok's Privacy Policy.

No other third parties receive any data.

5. Third-Party Account Access

PostFlow accesses only the TikTok account of the currently authenticated user. We do not access, collect, or process data from any other TikTok accounts. We do not perform any competitive analysis, scraping, or monitoring of third-party content.

6. Data Storage and Security

OAuth tokens are stored in a server-side session with a short expiration window. They are never written to a database or log file. Video files are not stored on our servers — they are streamed directly to TikTok's API upon posting. All communication between the App and TikTok uses HTTPS.

7. Your Rights

  • Access: You can view the data associated with your session at any time.
  • Deletion: Logging out immediately clears all session data. You may also revoke PostFlow's access via your TikTok account settings at any time.
  • Portability: No personal data is stored beyond the session, so there is nothing to export.

8. TikTok Platform Policy Compliance

PostFlow is built in compliance with:

  • TikTok Terms of Service
  • TikTok Developer Platform Policy
  • TikTok Data Portability guidelines

Data obtained through TikTok APIs is used only within the scope of the permissions granted and is not transferred, sold, or used for any purpose outside of this App.

9. Changes to This Policy

If we make material changes to this Privacy Policy, we will update the effective date above. Continued use of the App after changes are posted constitutes acceptance of the updated policy.
